Anvil

A native macOS agent harness. Swift 6 and SwiftUI, local and cloud models, artifacts, computer use, git and terminal, all in one app.

View on GitHub Project status 
$ git clone https://github.com/noktirnal42/Anvil.git
$ cd Anvil
$ swift build
Build complete!
$ open Package.swift   # opens in Xcode 27

Everything in one native window

Built for macOS with native controls, Keychain-backed secrets, and a theme system that includes a Matrix mode.

Artifacts

Code, Markdown, and HTML outputs kept with version history.

Quick open

File index and quick-open that search the project as you type.

Computer use

WebKit browser and Accessibility-based control of the desktop, with approval prompts.

Git status

See changed files and branches without leaving the app.

Terminal

A real PTY terminal next to your chat.

MCP tools

Connect Model Context Protocol servers and approve each tool call.

Local and cloud models

Providers for OpenAI-compatible endpoints, plus Anthropic and Google Gemini. Local servers such as LM Studio and Ollama work too.

Themes

Warm minimal, graphite, terminal heritage, and Matrix Techy.

Project status

Anvil is under active development. Here is where things stand.

  • Shipping now: the v1 app, which runs the OpenCode CLI as an embedded server.
  • In progress (v2.0): a native Swift session engine that talks to model providers directly, removing the CLI dependency.
  • Planned: notarized DMG releases and automatic updates.
